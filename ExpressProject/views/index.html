AI Project 技术文档

1. 项目概述

AI Project 是一个监控系统，集成了环境数据采集、设备管理、机器人控制等功能。项目采用Express框架构建，使用MySQL作为数据库。

1.1 核心功能

  • 用户认证与管理：JWT认证、用户CRUD操作
  • 设备状态监控：设备统计、状态监控
  • 传感器管理：传感器CRUD、数据采集
  • 环境数据监控：温度、湿度、烟雾浓度监测
  • 系统状态监控：数据库连接、内存使用、CPU负载、磁盘使用、网络状态

1.2 技术栈

技术 版本 用途
Node.js 14.x+ 运行环境
Express ~4.16.1 Web框架
MySQL 5.7+ 数据库
mysql2 ^3.20.0 MySQL驱动
jsonwebtoken ^9.0.3 JWT认证
bcrypt ^6.0.0 密码加密
socket.io ^4.8.3 WebSocket支持
winston ^3.11.0 日志管理

3. 环境配置

3.1 环境变量配置

创建 .env 文件，配置以下内容：

# 数据库配置
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=ai_project

# 服务器配置
PORT=3000
NODE_ENV=development

# JWT配置
JWT_SECRET=your_jwt_secret_key
JWT_EXPIRES_IN=24h

# Socket配置
SOCKET_PORT=443
SOCKET_HOST=0.0.0.0
SOCKET_TIMEOUT=300000

4. API接口文档

4.1 认证接口

4.1.1 用户登录

  • URL: POST /api/auth/login
  • 描述: 用户登录获取JWT token
  • 请求参数:
参数名 类型 必填 描述
username string 是 用户名
password string 是 密码
phone string 是 手机号
  • 请求示例:
{"username": "admin", "password": "123456", "phone": "13800138000"}
  • 响应示例:
{"code": 200, "message": "登录成功", "data": {"token": "eyJhbGciOiJIUzI1NiIs...", "userInfo": {"id": "1", "username": "admin", "role": "1", "avatar": null}}, "timestamp": "2026-04-02T00:00:00Z"}

4.1.2 用户注册

  • URL: POST /api/auth/register
  • 描述: 用户注册
  • 请求参数:
参数名 类型 必填 描述
username string 是 用户名
password string 是 密码
confirmPassword string 是 确认密码
email string 是 邮箱
phone string 是 手机号

4.2 用户管理接口

4.2.1 获取用户列表

  • URL: GET /api/users
  • 描述: 获取用户列表，支持分页和筛选
  • 查询参数:
参数名 类型 必填 默认值 描述
page number 否 1 页码
pageSize number 否 10 每页条数
role string 否 - 角色ID
status string 否 - 状态
keyword string 否 - 关键词

4.2.2 添加用户

  • URL: POST /api/users
  • 描述: 添加新用户

4.2.3 更新用户

  • URL: PUT /api/users/:userId
  • 描述: 更新用户信息

4.2.4 删除用户

  • URL: DELETE /api/users/:userId
  • 描述: 删除用户

5.2 传感器数据表结构

CREATE TABLE sensor_data (
  id INT AUTO_INCREMENT PRIMARY KEY,
  device_id VARCHAR(50),
  temperature DECIMAL(5,2),
  humidity DECIMAL(5,2),
  smoke_level INT,
  max_temp DECIMAL(5,2),
  human_detected BOOLEAN DEFAULT FALSE,
  fire_risk VARCHAR(20) DEFAULT 'low',
  env_status VARCHAR(20) DEFAULT 'normal',
  battery INT DEFAULT 100,
  record_time DATETIME DEFAULT CURRENT_TIMESTAMP,
  INDEX idx_device_id (device_id),
  INDEX idx_record_time (record_time)
) PARTITION BY RANGE (TO_DAYS(record_time)) (
  PARTITION p202604 VALUES LESS THAN (TO_DAYS('2026-05-01')),
  PARTITION p202605 VALUES LESS THAN (TO_DAYS('2026-06-01')),
  PARTITION p202606 VALUES LESS THAN (TO_DAYS('2026-07-01')),
  PARTITION p202607 VALUES LESS THAN (TO_DAYS('2026-08-01')),
  PARTITION p202608 VALUES LESS THAN (TO_DAYS('2026-09-01')),
  PARTITION p202609 VALUES LESS THAN (TO_DAYS('2026-10-01')),
  PARTITION p202610 VALUES LESS THAN (TO_DAYS('2026-11-01')),
  PARTITION p202611 VALUES LESS THAN (TO_DAYS('2026-12-01')),
  PARTITION p202612 VALUES LESS THAN (TO_DAYS('2027-01-01')),
  PARTITION pmax VALUES LESS THAN MAXVALUE
);

5.3 用户表结构

CREATE TABLE users (
  id VARCHAR(50) PRIMARY KEY,
  username VARCHAR(50) NOT NULL UNIQUE,
  email VARCHAR(100) NOT NULL UNIQUE,
  password_hash VARCHAR(255) NOT NULL,
  phone VARCHAR(20),
  role_id INT DEFAULT 2,
  status ENUM('active', 'inactive') DEFAULT 'inactive',
  last_login DATETIME,
  failed_login_attempts INT DEFAULT 0,
  last_failed_login DATETIME,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  INDEX idx_username (username),
  INDEX idx_email (email),
  INDEX idx_status (status)
);
